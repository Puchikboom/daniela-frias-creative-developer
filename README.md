# Daniela Frías — Creative Developer Portfolio (ES/EN)

Astro site with six supplied projects, original media, creative coding lab, bilingual case pages and Wix archive links.

## Run locally
```
npm install
npm run dev
```
Visit http://127.0.0.1:4321/es/ or /en/.

## Build
```
npm run build
npm run preview
```
Deploy `dist/` to a static host (Cloudflare Pages, Netlify, etc.).
